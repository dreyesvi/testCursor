# hello-app

Small static web page: HTML layout, CSS styling, and a click handler in JavaScript.

## Run

Open `index.html` in a browser, or from this folder:

```powershell
npx --yes serve .
```

Then visit the URL `serve` prints (usually `http://localhost:3000`).

## Layout

- `index.html` — page structure and the button
- `styles.css` — layout and colors
- `app.js` — greeting rotation on click
